Sobre o treino

Aprendizagem por gradientes no modelo PyTorch. O dataset deve ter pelo menos 1 MB. Não executes a Nord CLI em simultâneo.

Os checkpoints são guardados a cada 50 atualizações; interromper pode perder as últimas atualizações ainda não guardadas.

Professor · aprovar exemplos

Escreve um exemplo de pergunta e uma resposta correta. Os exemplos são guardados para revisão, mas não treinam automaticamente o modelo.

Boas práticas

Prefere respostas naturais em português europeu. Não coloques palavras-passe, dados pessoais ou informações confidenciais nos exemplos.

A integração destes exemplos no treino supervisionado é uma fase posterior.

Avaliação neuronal

O treino atual regista a perda de validação em exemplos reservados e gera respostas de pré-visualização.

Ainda não existe uma avaliação automática independente de fluência ou qualidade factual.

Inicia uma sessão para obter métricas.

Segurança e ambiente

Autenticação por token por pedido. O token é mantido apenas em memória neste separador.

Para acesso fora da rede privada, configura TLS e controlo de acesso no proxy. Não exponhas diretamente a porta 8765.
